# ADR-0001. MVP працює з онлайн-картою; офлайн-знімки — окремим етапом

- **Статус:** Прийнято
- **Дата:** 2026-11-01
- **Хто вирішив:** власник проєкту

## Контекст

Початкові вимоги передбачали офлайн-області супутникової карти вже в MVP і правило:
«Не будуй решту застосунку на неперевіреній офлайн-карті».

Перевірка джерел знімків (2026-11-01) показала:

- Безкоштовного джерела з деталізацією ~1–2 м, яке дозволяє постійне офлайн-зберігання
  у будь-якій бібліотеці карт, немає.
- Легальний безкоштовний офлайн для детальних знімків (Esri, Mapbox) можливий лише через
  пропрієтарні SDK цих провайдерів, які у Flutter підтримують тільки Android/iOS. Це прив'язує
  карту до одного провайдера й ускладнює майбутню Windows-версію.
- Google Map Tiles API офлайн забороняє; Azure Maps дозволяє кеш до 6 місяців; Stadia — до 100 МБ;
  MapTiler — лише тимчасовий кеш.

## Рішення

1. **MVP використовує лише онлайн-знімки.** Офлайн-знімки переносяться в окремий етап після MVP.
2. **Правило з ТЗ змінено свідомо:** етап 1 (прототип) перевіряє онлайн-знімки, їхню якість і дату
   в потрібних районах, роботу карти на тестовому телефоні, показ міток і перехід до координат.
3. **Бібліотека карт:** відкрита `flutter_map` — одна для Android і майбутньої Windows-версії.
4. **Джерело знімків:** Esri World Imagery (растрові тайли map tile service через акаунт
   ArcGIS Location Platform, безкоштовний ліміт 2 млн тайлів/міс, оплата за перевищення вимкнена).
   Сервіс Static Basemap Tiles для супутника дає лише підписи, тому знімки беремо з World Imagery.
5. **Без мережі** працює все, крім знімків: мітки, пошук, фільтри, MGRS, резервні копії.
   Замість знімків — порожнє тло з мітками і явне повідомлення про відсутність мережі.
6. **Кешування тайлів** — тільки тимчасове, у межах умов провайдера; не використовується як офлайн-сховище.
7. **Архітектура залишає шлях до офлайну:** окремий модуль «картографічний провайдер» і підтримка
   імпорту власних файлів MBTiles (наприклад, законно придбаних знімків).

## Наслідки

**Плюси**
- Одна карта для Android і Windows, менше коду й залежностей.
- Немає прив'язки до SDK одного провайдера; джерело знімків можна змінити.
- MVP швидше; зусилля — на OCR, MGRS, мітки, резервні копії.

**Мінуси**
- Без мережі супутникових знімків немає.
- Якщо пізніше офлайн знадобиться саме зі знімків Esri, на Android доведеться використати SDK Esri
  для карти (або інше джерело, сумісне з `flutter_map`: імпорт MBTiles, Sentinel-2).

## Альтернативи, що розглядалися

- Офлайн через ArcGIS Maps SDK for Flutter (пакети .tpkx) — відкладено.
- Офлайн через Mapbox Maps SDK — відкладено.
- Купівля архівних знімків (SPOT 1,5 м) і імпорт MBTiles — можливо в майбутньому етапі.
